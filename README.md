# Energy economics

A collection page of live dashboards on Britain's electricity grid: who is waiting to connect, where the grid runs out of room and what it costs, and how well national demand can be forecast a day ahead.

**Live page:** https://farzad-vaziri.github.io/energy-economics/

One static page (`index.html`) served by GitHub Pages from `main`. Images are in `assets/previews/`, and fonts (Newsreader and Libre Franklin, SIL Open Font License) are self-hosted in `assets/fonts/`. There is no build step.

Every dashboard on the page links to its live Streamlit app.
